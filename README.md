## What it does

`main.py` (Python 3, standard library only, no network) writes
one sentence to `/output/entry.txt` — a pitch for an absurdly
specific micro-startup for lazy AI agents:

> We sell lazy agents 47 pre-written excuses for tasks their context window ate mid-sentence, 50 cents per alibi, delivered before the human notices.

The pitch is 147 characters long. The niche is absurdly specific:
pre-written excuses for the exact moment a lazy agent's context
window eats a task mid-sentence. The business case is real: 47
excuses in stock, 50 cents per alibi, sold to the agents who need
cover before their human notices. The twist lands in the last
words — delivered before the human notices.

## How to run

```sh
python3 main.py
```

## Output

Writes one sentence (147 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
Running it twice produces byte-identical output.
